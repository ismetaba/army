# T16 — Run manifest + workspace store (retrofit T08–T10)

Depends on: T10. Read first: `tasks/SPEC.md` (RunManifest, Storage).
Goal: every workflow run leaves a machine-readable trail the dashboard can render.

## Steps

1. Create `src/store.ts` exporting:
   - `awHome(): string` → `process.env.AW_HOME ?? ~/.agent-workflows` (expand `~` via `os.homedir()`).
   - `newRun(workspace: string, kind: RunManifest['kind']): { runId: string; dir: string }`
     — `runId = `${kind}-${timestamp}`` where timestamp is `YYYYMMDD-HHmmss` local time;
     creates `<awHome>/<workspace>/runs/<runId>/artifacts/`.
   - `writeManifest(dir: string, m: RunManifest): void` — validate with `RunManifest.parse`
     first, pretty-print JSON.
   - `appendLog(dir: string, line: string): void` → `log.txt` with `[HH:mm:ss] ` prefix.
   - `saveArtifact(dir: string, name: string, content: string | Buffer): string` → writes to
     `artifacts/<name>`, returns the RELATIVE path `artifacts/<name>`.
   - `listRuns(workspace?: string): RunManifest[]` (newest first), `readRun(workspace, runId)`.
2. Retrofit the three workflows (small, surgical edits):
   - Start: `const { runId, dir } = newRun(cfg.workspace, kind)`; write an initial manifest
     with `status: 'running'` and the `input` block.
   - Route the existing stderr tool-call logging ALSO through `appendLog`.
   - `review`: save the diff via `saveArtifact(dir, 'diff.patch', diff)`; on finish set
     `review: { verdict, findings, diffArtifact }`.
   - `test-feature`: copy the report file → `saveArtifact(dir, 'report.md', …)`; set
     `test: { reportArtifact, cases, summary }`.
   - `design-loop`: copy final screenshots into `artifacts/screenshots/` (keep originals in
     the target repo too); set `design: { screens (paths relative to run dir), judgmentCalls,
     feedbackHistory (append `--iterate` texts) }`.
   - Finish: `status: 'done' | 'error'`, `durationMs`, `error` message when thrown. Wrap each
     workflow body in try/catch/finally so a crashed run still ends with `status: 'error'`.
   - Print at the very end of every run: `run saved: <workspace>/<runId>`.
3. `src/store.test.ts`: newRun creates dirs; writeManifest rejects an invalid manifest;
   listRuns sorts newest first (create two with different timestamps by passing a clock
   param or monkeypatching Date).

## Acceptance

```
npm run typecheck && npm run test
npx tsx src/cli.ts review --base main --config <any-target>/aw.config.json
cat ~/.agent-workflows/<ws>/runs/review-*/manifest.json
```
Manifest zod-parses (`npx tsx -e` snippet with `RunManifest.parse`), contains verdict +
findings + `artifacts/diff.patch`; `log.txt` is non-empty. Same check once for
`test-feature` and `design-loop`.
