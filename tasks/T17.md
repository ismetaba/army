# T17 — Dashboard skeleton

Depends on: T16. Read first: `tasks/SPEC.md` (Storage, port 4400).
Goal: Next.js panel listing workspaces and runs, with run-detail routing.

## Steps

1. From the repo root:
   ```
   npx create-next-app@latest dashboard --ts --app --tailwind --eslint --src-dir --import-alias "@/*" --use-npm
   ```
   Answer any extra prompts with the default. Then in `dashboard/package.json` set the dev
   script to `next dev -p 4400`.
2. Enable importing repo-root code: in `dashboard/next.config.ts` set
   `experimental: { externalDir: true }`; in `dashboard/tsconfig.json` add
   `"../shared/**/*"` to `include` and path alias `"@shared/*": ["../shared/*"]`.
   Verify `import { RunManifest } from '@shared/schemas'` compiles (schemas only — do NOT
   import from `src/`, it may pull node-only deps into client bundles; server routes only).
3. Data access `dashboard/src/lib/store.ts` (server-only): re-implement the READ side against
   the same layout — `awHome()`, `listWorkspaces()` (parse `workspaces.json`),
   `listRuns(ws?)`, `readRun(ws, id)`, `readArtifact(ws, id, relPath)` (resolve + REJECT
   paths escaping the run dir). Validate everything with the zod schemas.
4. Routes (server components, plain Tailwind, no extra UI libs):
   - `/` — workspace cards (name, repoRoot, run count) + latest 20 runs across workspaces.
   - `/ws/[ws]` — run table: runId, kind, agent, provider/model, status badge
     (running=blue, done=green, error=red, cancelled=gray), createdAt, duration; filter by
     kind via searchParam `?kind=`.
   - `/ws/[ws]/run/[id]` — generic run detail: manifest summary header + tabs placeholder
     (`Review | Report | Design | Log`); Log tab shows `log.txt` (monospace, tail last 500
     lines). Type-specific tabs are T18–T20 — render "coming soon" for now.
   - `/api/artifact?ws=&run=&path=` — streams an artifact file with correct content-type
     (png/webm/md/patch), 404 on traversal or missing.
5. Header nav: app name, workspace switcher (links), nothing fancy.

## Acceptance

```
cd dashboard && npm run dev
```
Open http://localhost:4400 — with ≥2 workspaces and ≥3 runs present (create with real runs
or hand-written valid manifests): home lists them; workspace page filters by kind; run page
shows header + Log tab content; `/api/artifact` serves a real `diff.patch` and 404s on
`path=../../etc/hosts`.

## Out of scope
No mutations, no triggering (T22), no type-specific views (T18–T20).
