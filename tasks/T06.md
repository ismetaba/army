# T06 — Playwright toolset

Depends on: T05. Read first: `tasks/SPEC.md` (viewports, screenshot naming).
Goal: browser tools an agent can drive; screenshots land in the agreed structure.

## Steps

1. Create `src/tools/browser.ts` exporting
   `makeBrowserTools(opts: { screenshotDir: string; viewports: AwConfig['viewports'] })`:
   - Module-level lazy singleton: `chromium.launch({ headless: true })`, one `BrowserContext`
     per viewport name, created on first use; `page` per context. Attach
     `page.on('console')` and `page.on('pageerror')` collectors per page.
   - Tools:
     - `browser_goto { url, viewport }` → `page.goto(url, { waitUntil: 'networkidle', timeout: 30000 })`,
       returns final URL + title. `viewport` is `'mobile' | 'desktop'` (defines which context).
     - `browser_screenshot { screen, viewport }` → full-page PNG to
       `<screenshotDir>/<screen>-<viewport>.png` (create dirs), returns the path.
     - `browser_click { selector, viewport }`, `browser_fill { selector, value, viewport }`
       (30 s timeouts, return `{ error }` on failure — never throw).
     - `browser_console_errors { viewport }` → collected `error`-level console messages +
       pageerrors since last call, then clears the buffer.
   - Export `closeBrowser(): Promise<void>` and call it from workflows on completion.
2. `screen` and every path segment: slugify with
   `s.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '')` — put `slugify` in
   `src/util.ts` and export it (reused by T09/T10/T16).
3. Create `scripts/browser-smoke.ts`: takes a URL arg (default `https://example.com`),
   screenshots it at both default viewports into `screenshots/smoke/`, prints the two paths,
   prints console error count, closes the browser.

## Acceptance

```
npx tsx scripts/browser-smoke.ts
ls screenshots/smoke   # example-domain… no: expect smoke-mobile.png and smoke-desktop.png
```
Both PNG files exist and are non-empty; script exits 0.
(Use `screen: "smoke"` in the smoke script so names are exactly `smoke-mobile.png`, `smoke-desktop.png`.)
