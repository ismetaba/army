# T04 — `aw ping` smoke command

Depends on: T03. Read first: `tasks/SPEC.md` (CLI commands).
Goal: verify each provider answers a one-prompt round trip, with readable failures.

## Steps

1. Create `src/commands/ping.ts` exporting `registerPing(program: Command)`:
   - Options: `--provider <p>` (default `lmstudio`), `--model <m>`, `--config <path>`.
   - Model resolution: if `--model` missing, try `loadConfig` (ignore load errors and then
     REQUIRE `--model` for providers other than defaults) → `resolveModel('code-reviewer', flags, cfg)`
     is NOT used here; ping resolves directly: flags → config.defaults.
   - For provider `claude-cli`: instead of `getModel`, run
     `claude -p "Reply with exactly: pong" --output-format text` via `child_process.execFile`
     with 60 s timeout; treat non-zero exit or "Not logged in" in output as failure and print
     the known fix: run `claude` interactively once, or use provider `anthropic`.
   - Other providers: `const t0 = Date.now(); const r = await generateText({ model, prompt: 'Reply with exactly: pong' });`
     then print one line: `OK <provider> <model> <ms>ms — "<first 40 chars of r.text>"`.
   - Error mapping: `ECONNREFUSED` or `fetch failed` on lmstudio →
     `LM Studio is not reachable at <baseURL>. Start LM Studio and enable the local server.`;
     missing env key → the requireEnv message. Always exit 1 on failure.
2. Register in `src/cli.ts`: `registerPing(program)`.

## Acceptance

```
npx tsx src/cli.ts ping --provider lmstudio --model <id loaded in LM Studio>   # OK line
npx tsx src/cli.ts ping --provider anthropic --model claude-sonnet-5           # OK line (key set)
npx tsx src/cli.ts ping --provider openai --model gpt-5                        # OK line, or clear key error
npx tsx src/cli.ts ping --provider claude-cli                                  # OK or documented "Not logged in" message
```
At minimum lmstudio AND one cloud provider must return OK; the other two must fail with
the exact readable messages above (not stack traces).
