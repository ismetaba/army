# agent-workflows

Toolkit providing three provider-selectable agent workflows (design-loop, test-feature,
review) for any target repo. TypeScript + AI SDK; agents defined in agents/*.md; runs
stored under ~/.agent-workflows/<workspace>/runs/.

## Commands
- CLI: `npx tsx src/cli.ts <ping|review|test-feature|design-loop|init>` (see tasks/SPEC.md)
- Typecheck: `npm run typecheck` · Tests: `npm run test`
- Dashboard (Phase 7): `cd dashboard && npm run dev` → http://localhost:4400
- Headless review: see README § Headless review

## Conventions
- Fixed decisions live in tasks/SPEC.md — follow them; do not introduce new tools,
  deps, or layout changes without asking.
- Shared types/schemas: shared/schemas.ts is the single source of truth.
- Agent prompts: agents/*.md; .claude/ is GENERATED by scripts/sync-claude.ts — never
  edit .claude/ by hand.

## Guardrails
GUARDRAILS (non-negotiable):
- Never run `git push`. Never create or comment on PRs. The human does that.
- Never target production. Staging only when an explicit staging URL is configured.
- Never commit secrets, .env files, or screenshots containing real user data.
- Ask before adding any dependency.
- Never run destructive operations (deletes, migrations, bulk writes) against a
  non-local target without explicit confirmation.
- When uncertain about a product decision, present options; do not silently guess.
- End design/test work by presenting artifact file paths, then STOP for feedback.
